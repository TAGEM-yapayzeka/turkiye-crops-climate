# Türkiye's Crops in a Changing Climate

T.C. Tarım ve Orman Bakanlığı, TAGEM · COP31 (Antalya, 9–20 Kasım 2026) standı için dijital ikiz uygulamasının web kopyası.

**Aç:** https://tagem-yapayzeka.github.io/turkiye-crops-climate/

Bu depo yalnız derlenmiş uygulamayı içerir (GitHub Pages). İklim senaryolarına göre 32 ürünün Türkiye'deki iklimsel uygunluğu: WorldClim 2.1, 8 CMIP6 modeli × SSP1-2.6 / SSP2-4.5 / SSP5-8.5, SoilGrids, CHIRPS, ESA WorldCover, ECOCROP, TÜİK. Fotoğraf atıfları ve kaynakça uygulamanın "Yöntem" sayfasındadır.

Web copy of the TAGEM COP31 stand app (built files only). Data sources and photo credits are listed on the app's Method page.
